# Design sources

Original artwork. Not served to users; the app uses the web-ready copies in `public/img/`.

| Folder | Contents |
|---|---|
| `logo/` | Master SVGs: wordmark on dark and light, lockups, app icon (square and rounded) |
| `mascots/source/` | Full-size mascot PNGs: `host.png`, `explorer.png`, `champion.png`, and `expressions-sheet.png` (3 large + 9 small expressions) |

After changing anything in `mascots/source/`, run `npm run mascots` (see `tools/build_mascots.py`).
A backup of every original is in Google Drive → Kalakal → 02 Mascots → Originals.
